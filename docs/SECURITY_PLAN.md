## 2. Цели и требования безопасности

- Конфиденциальность (логины/заметки не должны утекать)
- Целостность (без несанкционированных изменений)
- Доступность (приложение должно быть доступно авторизованным пользователям)
- Соответствие принципу минимальных привилегий
- ...

## 3. Оценка угроз

### 3.1. На стороне веб-приложения

- SQL-инъекции (ПР4)
- XSS (отражённый/хранимый)
- IDOR / недостаточный контроль доступа
- Запуск в режиме debug (отладочная информация)

### 3.2. На стороне БД (PostgreSQL)

- Доступ к БД с недоверенных IP
- Отсутствие шифрования (без SSL)
- Избыточные права пользователей (PUBLIC, owner)

### 3.3. Сетевые угрозы

- Перехват трафика
- Несанкционированный доступ в обход приложения
